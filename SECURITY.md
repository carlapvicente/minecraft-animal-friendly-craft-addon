| Versão | Suporte |
| ------ | ------- |
| Mais recente | ✅ |
| Versões anteriores | ❌ |

## Relato de vulnerabilidades

Se você identificar uma vulnerabilidade de segurança no Animal Friendly Craft Add-on, evite publicar detalhes sensíveis em uma Issue pública do GitHub.

Sempre que possível, utilize o recurso de relato privado de vulnerabilidades disponível neste repositório.

Ao enviar um relato, inclua:

- Uma descrição clara da vulnerabilidade
- Passos para reproduzir o problema
- A versão afetada
- Logs ou capturas de tela relevantes
- Possível impacto, caso seja conhecido

O relato será analisado e uma resposta inicial será fornecida assim que possível.

## Escopo

Os relatos de segurança podem incluir problemas relacionados a:

- Código-fonte do add-on
- Workflows de build e release
- Dependências do projeto
- Automações do repositório

Problemas relacionados ao próprio Minecraft, Mojang Studios, serviços da Microsoft ou ferramentas de terceiros devem ser reportados diretamente aos respectivos responsáveis.
