# Couro Sintético

🇧🇷 Português • [🇺🇸 English](synthetic-leather.en-US.md)

Uma alternativa ao couro que pode ser produzida sem precisar machucar animais.

</div>

---

## 🌱 Visão geral

O **Couro Sintético** é um novo item adicionado pelo **Animal Friendly Craft Add-on** como uma alternativa para obtenção de couro durante a sobrevivência.

Ele pode ser produzido utilizando materiais obtidos sem precisar machucar animais e, depois de criado, pode ser convertido em **couro vanilla**.

Isso permite utilizar o material nas receitas normais do Minecraft que exigem couro.

---

## 🧰 Ingredientes

Para produzir **2 Couros Sintéticos**, são necessários:

| Ingrediente        | Quantidade |
| ------------------ | ---------: |
| Papel              |          4 |
| Bambu              |          4 |
| Lã de qualquer cor |          1 |

> A lã pode ser de **qualquer uma das 16 cores disponíveis no Minecraft**.
