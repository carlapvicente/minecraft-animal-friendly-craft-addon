# Security Policy

[🇧🇷 Português](SECURITY.md) • 🇺🇸 English

## Supported Versions

Security fixes are currently provided for the latest released version of the Animal Friendly Craft Add-on.

| Version | Support |
| ------- | ------- |
| Latest | ✅ |
| Previous versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in the Animal Friendly Craft Add-on, please avoid publishing sensitive details in a public GitHub Issue.

Whenever possible, use the private vulnerability reporting feature available in this repository.

When submitting a report, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version
- Relevant logs or screenshots
- The possible impact, if known

The report will be reviewed and an initial response will be provided as soon as possible.

## Scope

Security reports may include issues related to:

- Add-on source code
- Build and release workflows
- Project dependencies
- Repository automation

Issues related to Minecraft itself, Mojang Studios, Microsoft services, or third-party tools should be reported directly to their respective maintainers.
